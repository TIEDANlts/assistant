# ADR 0008：敏感字段以占位符交给模型，由代码代入真实值

- 状态：已接受
- 日期：2026-09-23
- 关联：PLAN.md「横切关注点」、Phase 3

## 背景

模型可能部署在云端；而邮件草稿和 ehall 表单需要学号、身份证号、手机号等敏感信息。

## 决策

- `vault/profile` 中的敏感字段标记为 secret。
- 提示词里只出现 `{{profile.xxx}}` 占位符；生成最终内容（邮件正文、表单值）时由代码代入真实值。
- 确认页上敏感字段只显示后 4 位；日志和卷宗事件不记录原值。

## 后果

- 模型看不到原值，代入是确定性的、可测试的（“提示词中不出现 secret 字段原值”作为测试）。
- 代价：模型不能基于原值推理，格式校验之类的工作由代码完成。

## 放弃的方案

- 把原值直接写进提示词：泄露面大，且输出里的值不可控。

## 待验证

- 无。Phase 3 实现时补充占位符语法与缺失字段的处理。
